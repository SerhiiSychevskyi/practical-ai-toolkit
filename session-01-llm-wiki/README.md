# Session 01: LLM Wiki

Це наочний приклад того, як із одного неструктурованого матеріалу створити початок власної LLM Wiki.

У папці є два файли для роботи:

- [`prompt.md`](prompt.md) — готовий prompt із посиланням на концепцію LLM Wiki;
- [`synthetic-transcript.md`](synthetic-transcript.md) — вигаданий транскрипт без готового опису теми та списку учасників.

Приклад розрахований на coding agent або інше AI-середовище, яке має доступ до файлів у відкритій директорії.

## Як скористатися

1. Завантаж [`synthetic-transcript.md`](synthetic-transcript.md).
2. Відкрий порожню директорію в Codex, Claude Code або іншому агенті з доступом до файлів.
3. Скопіюй текст із [`prompt.md`](prompt.md).
4. Додай `synthetic-transcript.md` до того самого повідомлення та надішли його агенту.
5. Агент має прочитати концепцію за посиланням, створити структуру LLM Wiki та виконати перший Ingest для прикріпленого файла.

Цей варіант навмисно розрахований на агента з web access: учаснику не потрібно вручну копіювати текст концепції або заздалегідь класти source у директорію.

## Запит після Ingest

Коли агент завершить Ingest, постав йому таке запитання:

```text
Допоможи підготувати другий дзвінок щодо фічі з coins і платним parsing великих файлів.

Перевір такі сфери: product model, UX, pricing and payments, finance, engineering and reliability, security and fraud, support and refunds, analytics та rollout.

Для кожної сфери покажи один зі статусів:
- вирішено;
- обговорили, але рішення немає;
- лише згадали;
- у wiki немає інформації.

Потім окремо сформуй:
1. Підтверджені рішення та рамки.
2. Гіпотези й суперечливі думки учасників.
3. Відкриті питання та ризики.
4. Наступні дії з owners, якщо вони названі.
5. П'ять найважливіших питань для другого дзвінка, особливо щодо сфер, яких не обговорювали.

Для кожного наявного твердження дай посилання на source. Якщо інформації немає, прямо напиши “не знайдено в наявних джерелах” і не вигадуй відповідь. Не називай відсутність інформації доказом того, що тему ніколи не обговорювали поза матеріалами wiki.
```

Цей запит одночасно перевіряє, що wiki зберегла наявний контекст, і допомагає знайти прогалини перед наступним обговоренням.

Важливо: **«у wiki немає інформації» не означає «цього точно ніколи не обговорювали»**. Це означає лише, що інформацію не знайдено в матеріалах, які вже були додані до wiki.
