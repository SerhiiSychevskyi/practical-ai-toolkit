# Prompt

Перед відправленням заміни текст усередині `<llm-wiki-concept>` на повний текст [концепції LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f).

```text
Ось концепція LLM Wiki:

<llm-wiki-concept>
ВСТАВ СЮДИ ТЕКСТ КОНЦЕПЦІЇ LLM WIKI
</llm-wiki-concept>

Давай реалізуємо цей підхід у поточній директорії.

У директорії є мій перший файл `first-source.md`. Створи необхідну структуру LLM Wiki, а після цього виконай першу операцію Ingest для цього файла.

Не вигадуй відсутні факти або рішення, явно позначай невизначеність і зберігай можливість перейти від суттєвих тверджень до source.

Наприкінці коротко переліч створені або оновлені файли.
```
